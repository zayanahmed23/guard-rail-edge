# Security Policy

## Supported Versions

Security updates are applied to the latest minor version release.

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

The `guard-rail-edge` team takes prompt injection security, supply-chain safety, and credential isolation seriously.

If you believe you have found a security vulnerability in `guard-rail-edge` (such as an issue that allows remote execution, credential exfiltration, sandbox bypass, or circumvention of evaluation checks):

1. **Do not open a public GitHub issue.**
2. Send an email to **`zayanahmed222@gmail.com`** with the subject `[SECURITY VULNERABILITY] guard-rail-edge`.
3. Include detailed reproduction steps, proof of concept, and environment details.

### Response Time & Policy
- We acknowledge valid security reports within **48 hours**.
- We coordinate a patch and CVE assignment where applicable before public disclosure.
- Responsible disclosure is requested: please allow up to 30 days for remediation before publishing.
- Note: There is currently no paid bug bounty program. Contributors are credited in release notes.
